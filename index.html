Expression guide

Quick reference for calculated tags

Reference existing tags

Insert a tag from the editor selector or enter tag("TagID"). The latest GOOD sample is used.

tag("temperature_in")
(tag("line_pressure") * 1.25) + 2

Operators

+ - * / % ** for arithmetic; < <= > >= == != for comparisons; && || ! for logic. Use parentheses to make precedence explicit.

Available functions

min(a,b,…) · max(a,b,…)Minimum or maximum of multiple values.
sum(a,b,…) · avg(a,b,…)Sum or average of values.
abs(x) · round(x,n)Absolute value or rounding to n decimal places.
floor(x) · ceil(x) · sqrt(x)Floor, ceiling, and square root.
pow(x,y)Raise x to the power of y.
clamp(x,min,max) · limit(x,min,max)Clamp a value to the specified range.
scale(x,inMin,inMax,outMin,outMax)Scale a value from an input range to an output range.
bit(word,index)Returns the selected bit of an integer.
if(condition, true_value, false_value)Choose a result based on a condition.
coalesce(a,b,…) · concat(a,b,…)First available value or text concatenation.

Examples

round(tag("temperature") * 1.8 + 32, 1)
scale(tag("raw_entrada"), 0, 27648, 0, 10)
if(tag("run_status") == 1, tag("setpoint"), 0)
bit(tag("status_word"), 3)
clamp(tag("pressure") * 1.1, 0, 10)

Important: Only the functions and operators in this guide are supported. Arbitrary JavaScript is not executed. Unknown references and dependency cycles are rejected. Calculated tags do not write to a PLC unless an explicit automatic write rule is configured.
